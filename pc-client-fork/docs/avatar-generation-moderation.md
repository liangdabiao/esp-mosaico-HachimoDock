# 形象生成的参考图审核排查

## 本次结论（2026-09-21）

用户提供的 `volcano submit HTTP 400`、`InputImageSensitiveContentDetected.PolicyViolation` 和 `doubao-seedance-2-0-fast-260128` 请求摘要，指向图生视频提交时的输入图片审核失败，并非设备、Windows 编码、API Key 或视频参数问题。

平台原文为图片可能涉及版权限制，没有明确指出某个人脸或某个主体。本次素材中确实存在真人，结合平台的人像规则，人像授权是需要排查的原因，但不能将通用版权错误认定为已证实的人脸检测结果，也不能确定是前景人物还是背景内容触发。

后续经用户授权，使用原始 JPEG、不做背景处理，向同一 Fast 模型实际提交一次 5 秒视频任务，返回 HTTP 400、`InputImageSensitiveContentDetected.PrivacyInformation`，原文为 `may contain real person`。这次明确属于平台的人像隐私审核拦截，任务未成功创建；此结论不意味着所有通用版权错误都可归类为人像。

## 实际调用链

| 环节 | 实现 | 审核结论 |
| --- | --- | --- |
| 可选背景处理 | `image-processing.js` → `providers/volcano-image.js`，Seedream `/api/v3/images/generations` | 独立请求；失败时当前流程会回退原图。历史视频报错不能证明该环节成功或失败。 |

`content[1]`、`content[2]` 是同一张处理后的图片分别作为首帧和尾帧，用于循环动画，并非两张原图。不能从这两个字段推导出首尾帧配置有误。背景处理状态目前没有完整保留在最终失败摘要中，不能事后还原当次使用的是处理图还是回退原图。

## 合规解决路径与限制

火山提供真人认证、肖像授权和可信素材库；授权素材可通过 `asset://<asset_id>` 在视频 API 中引用。当前客户端上传的是 PNG data URL，未接入真人素材库、授权状态查询或素材引用流程。仅调整错误文案不能使被拒的照片生成成功。

支持真人素材需要单独接入平台授权流程，并验证当前模型支持的素材角色与循环动画效果；不能只把普通图片 URL 替换为资产 ID 就宣称完成。授权需由相关权利人完成，客户端不能代为确认。素材被误判时可携带平台请求 ID 联系火山复核。没有授权路径时，应使用符合平台要求的其他素材。

不将改尺寸、改时长、重复提交、关闭背景处理或静默切换模型包装成审核解决方案；图片处理成功也不保证视频审核通过。

## 本轮修改与验证范围

- 错误提示区分“图片背景处理（生图）失败”和“图生视频失败”。
- 只有平台明确提到真人/人脸时才显示“人像审核”；一般内容、版权或隐私代码不自动归因人像。
- 生成配置提前说明真人素材的授权要求和当前客户端限制。
- 图生视频审核失败与生成配置页提示：使用有权使用的素材，自行生成动态形象并导出 MP4，通过「形象画廊 → 新建自定义形象 → 自定义上传视频」上传，其他动作在详情页「上传 MP4 替换」中补充。仅说明现有上传方式，不承诺其他平台一定能生成。
- 保持明确输入图片拒绝后停止剩余动作、保留已成功结果的行为。
- 回归使用模拟响应，不重新上传用户照片，也不调用付费生图/视频接口。

不同产品的生成结果不能用于推断本项目应绕过当前模型规则。对比时应核实实际服务商、模型版本、图片预处理和素材授权，而不是只比较界面功能。
